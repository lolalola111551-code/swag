# LINGUA — AI Переводчик

Интеллектуальный переводчик на базе Ollama API (облако).

## Запуск

### Требования
- Node.js 18+ (скачать: https://nodejs.org)
- API ключ от https://ollama.com

### Шаги

1. Распакуй архив
2. Открой терминал в папке с файлами
3. Запусти сервер:

```bash
node server.js
```

4. Открой браузер: **http://localhost:3000**
5. Введи API ключ от ollama.com и нажми «Сохранить»

## Файлы

- `index.html` — интерфейс переводчика
- `server.js` — локальный прокси-сервер (Node.js, без зависимостей)

## Почему нужен сервер?

Браузер не может напрямую обращаться к `api.ollama.ai` из-за CORS-ограничений.
Сервер проксирует запросы: браузер → localhost:3000 → api.ollama.ai
